What happens when you load it?

This page includes its JavaScript runtimes and CPU WebAssembly engine. It loads Qwen3-0.6B weights and runs generation on your device. WebAssembly uses the CPU; WebGPU uses a compatible GPU and downloads a compiled model library. Neither option needs an inference API key or a model server.

The official CPU Q8 model is approximately 639 MB (610 MiB). The GPU Q4 option uses about 350 MB of model and tokenizer assets, plus its compiled library. GPU memory use is estimated at 1.4 GB with the upstream 4,096-token context. Downloads and working memory are different quantities.

What does “local” mean here?

  • Your messages are processed in this browser. They are not sent to an inference API.
  • Loading remote weights needs a network connection and contacts the model host. The GPU route also fetches its compiled model library.
  • Messages stay in memory unless you enable Remember this conversation, which saves them in this browser. Export only if you want a separate copy.
  • You can save this HTML and import a compatible Qwen3-0.6B GGUF file to use the CPU route entirely offline. Browser caches may be cleared or evicted; a cached model alone does not guarantee the hosted page will reopen offline.

Is this the 24 KB assembly operating system?

This is a browser implementation of the local inference experience, inspired by llm.asm. The original x86-64 operating-system binary cannot run directly as WebAssembly. Its model weights are separate from the tiny executable.

Performance depends on your browser, hardware, model format, and context length. The metrics below the conversation come from this session; they are not the assembly project's benchmark results.

For a good first run

Use a current desktop browser over HTTPS or localhost. Keep your first prompt short. If the GPU route is unavailable, choose WebAssembly. A 0.6B model is useful for experimentation and simple tasks; it has limited reasoning and factual reliability.

For a portable CPU setup, use Save HTML and download the matching official GGUF. Open the saved page and choose Use a local GGUF file. If your browser restricts local HTML workers, serve the same file from localhost.
