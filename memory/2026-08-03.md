# 2026-08-03

- Prepared 0.1 as a release-hardening baseline after a full pre-production
  review. The site remains static-only, with no bindings, credentials,
  authentication surface or learner data leaving the browser.
- Found CI drift: content graph, citation and contrast gates were documented
  but not executed, and ast-grep came from an unpinned `latest` download.
  Restored the gates, pinned the toolchain and actions, and added Gitleaks,
  dependency audit and an independent rendered-CSP regression.
- Local build produced 182 pages. Static security checks, dependency audit,
  content gates, link integrity, bundle budget and contrast passed. Real mobile
  Safari and desktop Chromium QA loaded the staging explorer; Chromium switched
  component state with nine successful network requests and no console errors.
- Production was still serving an older artifact: the explorer CTA routed to
  `/lessons/` and unknown routes returned an empty 404. Promotion of the current
  staging artifact is required after the release gate and explicit production
  confirmation.
- GitHub `main` had no branch protection. This is repository configuration,
  not a code defect; changing it needs an explicit policy decision.
- The first release CI run exposed a runtime mismatch: local Node 26 stripped
  TypeScript imports by default, while the declared Node 22.13 runner required
  `--experimental-strip-types`. The test script now enables that native flag.
- Staging version 16 (`f13a6cbb-39dd-4476-83d3-61ff8ecd6c19`) passed artifact,
  header, CTA, lesson and 404 smoke checks. A full benchmark attempt became
  inconclusive when local DNS failed mid-run; the documented pnpm 11 invocation
  was corrected from `pnpm bench -- --target ...` to `pnpm bench --target ...`.
- Consolidated release history and changelog into version 0.1. The canonical
  public site and production routes use `https://llmdeepdive.com/`.
