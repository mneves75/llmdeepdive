Open the parameter list of any recent large language model and count the matrices in one feed-forward block, the per-token MLP inside every layer. [Lesson 2.2](/lessons/2-neural-network-fundamentals/2.2-multilayer-perceptrons-nonlinearity/) described that block as up-project, activate, down-project: two matrices. Qwen3.8-27B has three per block, named gate, up, and down (Qwen3.8-27B Model Card, 2026). Something changed between the textbook picture and the shipped model, and the third matrix is where this lesson lives.

## What does a fixed activation like ReLU do?

Begin with what the textbook version does. An **activation function** sits between two learned affine maps (matrix multiplication plus a shift) and makes their composition nonlinear. **ReLU** is $\operatorname{ReLU}(x)=\max(0,x)$: positive inputs pass unchanged, negative inputs become zero. It is cheap and piecewise linear, with derivative one on the positive side and zero on the negative side.

As the default activation between hidden layers, ReLU replaced the older sigmoid and tanh, two S-shaped curves that flatten out for large positive or negative inputs. In those flat regions, called **saturated**, the derivative is close to zero, and that broad saturation had made deep networks hard to train. ReLU avoided it. Its own known hazard is its flat negative side. A unit's **pre-activation** is the value it computes before the activation is applied. If that value stays negative across all relevant examples, no gradient reaches the unit through the ReLU path, and the unit is effectively dead. Leaky variants keep a small negative slope to preserve a recovery route.

## How do GELU and SiLU smooth the corner?

**GELU** smooths the corner. It is usually written $x\Phi(x)$, where $\Phi$ is the standard normal cumulative distribution function: the probability that a bell-curve sample falls below the input. So the input is scaled by how far into the distribution it sits. Large positives pass almost untouched, large negatives are almost fully suppressed, and the transition near zero is gradual rather than a kink. GELU produces small negative outputs instead of hard zeros.

**SiLU**, also called swish in this form, is the close cousin $x\sigma(x)$, with the logistic sigmoid in place of $\Phi$. It has the same shape, is cheaper to evaluate, and is the one that ended up inside gated blocks.

## How is a gate different from a fixed curve?

Every function so far is a fixed curve applied elementwise. Feed it a number and it returns a number; the rule never depends on anything else. Here is the move that broke that pattern.

A **gated linear unit** projects the same input twice. One projection is the content, the other is a gate, and the two are multiplied together element by element (the $\odot$ symbol below). With SiLU on the gate branch this is **SwiGLU**:

$$
\operatorname{SwiGLU}(x)=\operatorname{SiLU}(xW_{g})\odot(xW_{u}),
$$

followed by the down projection $W_{d}$ back to the model width. That makes three matrices instead of two. The gate branch does not carry content forward. Its only job is to decide, per feature and per input, how much of the content branch survives.

Work one coordinate through with numbers. Suppose for some token the gate projection produces $-3.0$ at coordinate $j$ while the content projection produces $+8.0$ there. The gate value is $\operatorname{SiLU}(-3.0)=-3.0\times\sigma(-3.0)\approx-3.0\times0.047\approx-0.14$, so the output at that coordinate is about $-0.14\times8.0\approx-1.1$. A strong content signal has been almost entirely suppressed, and slightly inverted. Now take a different token where the same coordinate's gate projection is $+3.0$ instead. The gate becomes $3.0\times\sigma(3.0)\approx3.0\times0.953\approx2.86$, and the same content value of $8.0$ leaves as roughly $22.9$. Identical content, opposite fate, decided by the other branch. A fixed curve cannot do that: feed ReLU the value $8.0$ and it returns $8.0$ every single time, regardless of what the rest of the vector said.

:::insight
That is the whole conceptual step, and it recurs at every scale in this course. A fixed activation asks "is this number large?" A gate asks "given everything else about this token, should this feature be allowed through?" Multiplying by a value computed from the input is a different capability from bending a curve. Hold onto it: the same idea, applied to a recurrent state rather than a feature vector, is what [lesson 3.3](/lessons/3-sequence-models/3.3-lstm-gru-gates/) calls a forget gate. It is also what puts the word "Gated" in the Gated DeltaNet and Gated Attention layers that make up all 64 layers of this course's model.
:::

## How do you compare a gated block fairly?

Here is the classic wrong turn in evaluating this. You have a feed-forward block with intermediate width $d_{ff}$ and a GELU. You swap in SwiGLU, keep $d_{ff}$ the same, retrain, and measure a quality gain. It is tempting to report that gating helped. That claim is not clean. You also added an entire extra matrix of shape $d_{\text{model}}\times d_{ff}$, where $d_{\text{model}}$ is the model width, so parameters and compute rose by roughly fifty percent for that block. The gain may come from gating or from the added capacity, and the experiment cannot separate them. The standard correction is to shrink the intermediate width when adopting a gate, commonly to about two-thirds of the ungated value, so that the three-matrix block costs what the two-matrix block cost. Only then does the comparison isolate the mechanism.

:::warning
The most common misconception is that the gate is an interpretable switch: that a near-zero gate value means the model "decided this feature is irrelevant" in any human sense. It does not. Gate values are learned consequences of the loss, distributed across thousands of coordinates that interact, and a later projection can amplify or ignore whatever survived. Gates are a mechanism that changes the set of functions the model can express. They do not explain what the model knows.
:::

## Where does the gated block sit in Qwen3.8-27B?

Now put the numbers on the block. In Qwen3.8-27B each of the 64 layers holds one gated feed-forward block. It takes the 5120-dimensional hidden state, projects to an intermediate width of 17408 along both the gate and the up path, multiplies, and projects back to 5120. That is roughly 267 million parameters per layer, and near 17 billion across the model (Qwen3.8-27B Model Card, 2026). Whatever else gating is, it is where the majority of this model's parameters chose to live.

Two engineering cautions close the lesson. First, activations shape distributions across depth. Large inputs amplify outputs and gradients, saturated regions suppress learning, and nonzero means shift what following layers see. That is precisely why [lesson 2.8](/lessons/2-neural-network-fundamentals/2.8-initialization-normalization-residuals/)'s normalization and residual paths exist. Second, always check the exact formula and dtype (the number format, such as bf16, a 16-bit floating-point type) the implementation uses. GELU ships in exact and approximate forms. Fused kernels, which merge several operations into one GPU routine, reorder the arithmetic, and bf16 rounding differs from the symbolic curve. Two blocks sharing an activation's name can compute measurably different functions.
