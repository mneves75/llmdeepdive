[Lesson 3.2](/lessons/3-sequence-models/3.2-rnns-vanishing-gradient/) left a specific diagnosis, not a vague complaint. In a plain recurrent network (RNN), the state passes through the *same* multiplication and the *same* saturating nonlinearity at every step. So credit across $k$ steps is a product of $k$ Jacobians (matrices of local sensitivities), and the model does not control their factors. Two repairs follow directly from that diagnosis:

1. Give the state a path that is added to rather than transformed.
2. Let the model decide, per step and per feature, how much of the old state to keep.

## How an LSTM cell keeps a value

Both repairs are in the **LSTM** (Long Short-Term Memory) cell. Alongside the hidden output $h_t$, the cell maintains a separate cell state $c_t$, a vector that acts as its running memory. Three **gates** control it. A gate is a vector of numbers between zero and one, multiplied elementwise (coordinate by coordinate) into another vector, so it works like a set of dimmer switches. Each gate comes from a sigmoid, a function that squashes any number into the range zero to one, applied to a learned affine map (a matrix multiply plus an offset) of $x_t$ and $h_{t-1}$.

Follow one coordinate of the cell state through one step, with made-up numbers. The old value is 2. The forget gate is 0.9, so 0.9 × 2 = 1.8 of the old value survives. The new candidate content is 1, and the input gate is 0.5, so 0.5 × 1 = 0.5 is written. The new value is 1.8 + 0.5 = 2.3. In symbols, for whole vectors:

$$
c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t,
$$

followed by $h_t=o_t\odot\tanh(c_t)$. Here $f_t$, $i_t$, and $o_t$ are the forget, input, and output gates, $\odot$ is elementwise multiplication, and the candidate $\tilde c_t$ is the new content on offer. The output gate decides how much of the squashed cell state is shown as $h_t$.

Read the cell update as an instruction rather than a formula. The forget gate says, coordinate by coordinate, what fraction of the existing ledger survives. The input gate says how much of the new candidate gets written. The two are *added*, not composed. A coordinate whose forget gate sits at one and whose input gate sits at zero carries its value forward completely untouched: no matrix multiply and no nonlinearity touch it.

## What the forget gate does to the gradient

That changes the gradient path in exactly the way lesson 3.2 asked for. Hold the gate values fixed. Then the direct cell-state path from $c_k$ to $c_T$ contributes $\prod_{t=k+1}^{T} f_t$: the product of the forget gates. The weight matrices and the saturating derivative are absent from this direct route, and what remains is a quantity the network computes for itself. This product is not the whole total derivative, however. The gates and candidate also depend on the previous hidden state, which creates additional gradient paths.

## Why the gate value sets a half-life

Now work out what that product actually buys. Suppose a coordinate's forget gate settles at $0.99$. Over 100 steps the retained fraction is $0.99^{100}\approx0.366$: about a third of the signal survives, which is workable. Drop the gate to $0.9$ and the same 100 steps give $0.9^{100}\approx2.7\times10^{-5}$: gone. So the gate is not a switch between remember and forget. It sets an exponential **half-life**, the number of steps after which half of a stored value is left, and small differences in the gate value produce enormous differences in reach.

This makes initialization, the starting values of the parameters, matter more than people expect. Leave the forget gate's bias (the offset inside its affine map) at zero, and the sigmoid starts near $0.5$. At the beginning of training the cell then retains $0.5^{100}\approx8\times10^{-31}$ over a hundred steps: a half-life of one step. The model must first *learn* to remember before it can learn what to remember, and the gradient that would teach it has already vanished.

The standard fix is to initialize the forget-gate bias positive. At a bias of 3 the gate starts near $0.953$, and $0.953^{100}\approx0.008$. That is small but no longer astronomically dead, so the long-range gradient exists and can be improved. The wrong turn here is diagnosing the resulting failure as a learning-rate or capacity problem and tuning for days. The real cause is a bias initialization that made the memory path start in the off position.

## The GRU: fewer gates

A **GRU** (Gated Recurrent Unit) simplifies the design by merging cell and hidden state. An update gate interpolates between the previous state and a candidate, and a reset gate controls how much of the previous state contributes while the candidate is formed. Fewer gates and fewer parameters often give comparable quality. Exact equations vary by convention, notably whether the reset is applied before or after a matrix multiplication. Those variants are not numerically equivalent, so checkpoint compatibility (whether saved weights load correctly into an implementation) depends on the precise definition rather than the name.

## What gates did not solve, and where they reappear

:::warning
The most common misconception is that gates solved long-range memory. They did not; they extended it. The cell path still multiplies, the state is still finite, and [lesson 3.1](/lessons/3-sequence-models/3.1-modelling-sequences/)'s counting argument still holds: a bounded ledger with competing entries must eventually overwrite something. Gates also bring their own failure. A saturated gate, one pinned near zero or one, has a near-zero derivative, so a cell that has learned to hold a value near one learns slowly about when it should stop. LSTMs pushed usable dependency length from tens of steps into the hundreds, which transformed speech, translation, and time series. They did not make length free, and attention arrived a few years later for exactly that reason.
:::

Gate visualizations invite a second error. A coordinate showing a high forget value on a particular token does not prove that the unit "stores" a fact a human could name. State features are distributed, gates interact across thousands of coordinates, and a later projection can amplify or discard whatever was preserved. Causal intervention is evidence: clamp the coordinate and measure the behavioral change. A colorful heatmap is a hypothesis.

:::insight
Now the part that matters for the rest of this course. The word *gate* means one specific thing: a learned, input-dependent multiplier applied to something else. You have already met it once, in [lesson 2.3](/lessons/2-neural-network-fundamentals/2.3-activation-functions/), where a gate branch multiplies the content branch inside every feed-forward block of a modern model. You meet it again here, applied to a recurrent state. And it is the same word, meaning the same operation, in the layer names of this course's specimen: Qwen3.8-27B is built from **Gated DeltaNet** and **Gated Attention** layers (Qwen3.8-27B Model Card, 2026). In the DeltaNet layers the gate is a learned decay applied to a recurrent state. That is the forget gate of this lesson, promoted from a vector state to a matrix-valued one, which [lessons 3.6](/lessons/3-sequence-models/3.6-linear-attention-fast-weights/) and [4.15](/lessons/4-transformer/4.15-gated-deltanet/) develop. Gating did not survive as a historical footnote. It survived as one of the two or three mechanisms that every 2026 architecture is assembled from.
:::

To compare recurrent cells fairly, match total parameter count by adjusting hidden width rather than holding hidden size fixed. Equal hidden size flatters the smaller GRU on parameter cost, while equal parameters change the width and therefore the representation. Report latency and memory at the sequence lengths you actually care about. Test streaming state resets explicitly too: state carried across unrelated sequences produces impressive-looking numbers that are leakage rather than memory.
